El trabajo paralelo exige dividir una tarea grande en partes que puedan resolverse de manera coordinada. En este experimento usamos un mensaje suficientemente largo para comprobar que el cifrado no se limita al primer bloque de datos. Cada proceso recibe un intervalo de llaves posible y prueba una por una hasta encontrar una que permita recuperar una frase conocida. La frase elegida para validar el resultado es: la busqueda distribuida termina cuando aparece la frase clave. No es necesario conocer el texto completo para intentar la busqueda, pero si se necesita una senal confiable que indique que la llave probada produjo contenido valido.

El algoritmo se ejecuta con MPI porque cada proceso tiene memoria propia. Antes de iniciar la busqueda, todos los procesos disponen del mismo texto cifrado y de la misma frase de validacion. Luego el espacio de llaves se parte en intervalos contiguos. El proceso cero prueba el primer intervalo, el proceso uno el siguiente y asi sucesivamente. Cuando uno encuentra una coincidencia, avisa a los demas mediante mensajes MPI. Los demas revisan esos mensajes mientras trabajan y detienen la busqueda si reciben la llave ganadora.

Para esta practica se limita el espacio de prueba con un parametro. El DES real tiene cincuenta y seis bits efectivos de llave, por lo que recorrer todas sus posibilidades no es viable en una computadora de laboratorio. El limite reducido mantiene el comportamiento de distribucion, comunicacion y cancelacion, y permite obtener tiempos comparables. Las mediciones deben guardar el numero de procesos, la llave, el limite, el tiempo total y el tiempo de cada proceso. Con esos datos se calcula el promedio, el speedup y la eficiencia.

La prueba tambien ilustra que DES trabaja en bloques de ocho bytes. El mensaje se rellena hasta completar el ultimo bloque antes de cifrarse. Al descifrar, se vuelve a buscar la frase de validacion dentro de una copia temporal. Si aparece, la llave es candidata correcta. Este procedimiento no pretende romper DES en produccion; se usa un espacio acotado para observar el costo del enfoque de fuerza bruta y la manera en que MPI reparte el trabajo entre procesos independientes.
